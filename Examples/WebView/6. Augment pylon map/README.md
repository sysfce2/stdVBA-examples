# Augmenting Other Websites - Pylon Map

This example demonstrates how to augment an existing third-party web application inside `stdWebView` instead of rebuilding the application from scratch.
It uses a Scribble Maps pylon map and layers custom behavior on top via injected JavaScript and host-app integration patterns.

## What This Example Entails

This project shows how to:

- Navigate a `stdWebView` instance to a real-world application/map experience.
- Inject and run script in the correct execution context.
- Read and respond to map interactions (for example, right-click and point selection flows).
- Bridge map-side events and data back into host-side logic for higher-level workflows.
- Work with provider-specific map internals only when needed, while preferring stable integration points.

Target map:

- [Scribble Maps - Pylon Map UK](https://www.scribblemaps.com/maps/view/Pylon-Map-UK/olGrbyLDOr)

## Key Feature Demonstrations

- **Website augmentation over replacement**: Extend an existing business solution with your own features.
- **Deep map interaction capture**: Handle user interactions and resolve coordinates reliably.
- **Cross-context integration strategy**: Align navigation and script injection so your code can see the real interactive map surface.
- **Provider-aware implementation**: Detect and adapt to runtime map provider behavior (for example Leaflet APIs).
- **Pragmatic diagnostics**: Use runtime probing and event/API verification to reduce guesswork during integration.
